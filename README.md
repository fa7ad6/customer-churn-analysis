# customer-churn-analysis
Customer Churn Prediction using Machine Learning
📘 Customer Churn Analysis & Prediction
📌 Project Overview
This project analyzes customer data to identify factors influencing churn and builds machine learning models to predict customer churn.

📊 Key Features

Data Cleaning & Preprocessing
Exploratory Data Analysis (EDA)
Feature Engineering
Multiple Machine Learning Models
Model Evaluation using:
Accuracy
Precision
Recall
F1 Score
ROC Curve & AUC

🔧 Tools & Technologies

Python
Pandas, NumPy
Seaborn, Matplotlib
Scikit-learn
XGBoost

🤖 Models Used
Logistic Regression
Random Forest
Gradient Boosting
XGBoost

📈 Results
XGBoost performed best with strong recall and AUC, making it suitable for identifying potential churn customers.
